# 工单管理补充

日期：2026-11-07；本次实现不包含生产发布。

- 管理员在工单详情直接点击关闭，复用已有状态接口；执行中禁用按钮，失败保留工单和草稿，成功展示已关闭状态并刷新队列。
- 后台工单导航显示待客服处理数量（open 与 pending_admin），折叠菜单仍有可读提示。
- 新增管理员统计接口，仅返回工单总数和待处理数，不返回用户内容。
- 登录后台时提示已有待处理数量；此后每 30 秒检查新增工单并站内提醒，同一会话页面切换不重复提醒。
- 标签页隐藏时暂停检查，重新可见时刷新；退出或切换账户清理旧状态，失败不清零和弹出连续报错。
- 新工单提示不强制刷新当前会话，避免打断回复；回复和状态修改后更新角标。
- 验证：管理员直接关闭/失败重试、提醒去重、账户切换、统计语义、中英文文案及布局。

验证结果：35 项前端测试通过；工单后端与真实 PostgreSQL 集成通过；vue-tsc 与相关 ESLint 通过。Playwright 使用本地模拟接口实测关闭、新工单角标/提示、草稿保留以及桌面浅色/深色和手机布局。未向生产服务器发布。
