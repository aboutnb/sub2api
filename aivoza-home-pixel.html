Core Features

统一接口，稳定连接多种 AI 模型

从第一次请求到团队用量管理，Aivoza 把分散的模型能力收进一个清晰、可靠的入口。

01

统一 API，少写重复代码

获取一个 API 密钥，即可调用所有已接入模型。减少多套 SDK、鉴权和账单带来的维护成本。

02

智能调度，稳定响应

多个上游账号自动切换和负载均衡。健康状态实时参与调度，让单点波动不再打断工作流。

03

按量计费，用量透明

按实际使用量计费，支持额度控制与团队用量查看。每一次调用都清晰可追踪，更容易管理成本。

Quick Start

三步完成接入

把时间花在产品上，而不是重复配置不同模型供应商。

创建账号

登录 Aivoza 控制台，完成基础账户设置。

获取密钥

创建 API 密钥，并为不同项目设置独立额度。

发送请求

替换请求地址与密钥，即可开始调用模型。

熟悉的请求方式，更少的接入负担

保留已有开发习惯，用统一入口连接所需模型。

curl https://aivoza.com/v1/messages \ -H "Authorization: Bearer $AIVOZA_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "claude-sonnet", "messages": [...] }'
